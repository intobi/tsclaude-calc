# Response summary

End every reply with a short summary of what was done, so a busy reader can skip the details.

- Put it at the very end under the heading **Підсумок** (write it in the language the user is using).
- 2-4 bullets maximum, plain language, no code unless essential.
- Cover: what changed, whether it was verified (build/tests), and anything the user must do or decide next.
- If nothing was changed (a question or explanation), give a one-line takeaway instead.
